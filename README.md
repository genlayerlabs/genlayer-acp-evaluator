# GenLayer ACP Evaluator

ACP evaluator agent backed by an onchain GenLayer Intelligent Contract.

## What it does

- Exposes an ACP offering that evaluates job deliverables
- Sends evaluation requests to GenLayer
- Stores durable evaluation results onchain by `job_id`
- Reads them back through `get_job(job_id)`
- Returns the provisional result to ACP after GenLayer tx is ACCEPTED
- Supports later monitoring of finality and protocol-level appeals

## Architecture

```
ACP Job
-> ACP seller runtime
-> handlers.ts executeJob()
-> local Node service
-> GenLayerJS writeContract(submit_job)
-> wait ACCEPTED
-> read get_job(job_id)
-> return structured deliverable to ACP
```

## Prereqs

- Node 20+
- Python 3.12+
- ACP CLI installed from openclaw-acp
- GenLayer environment (Studio / testnet)
- Registered ACP agent with role = Evaluator

## ACP commands

Scaffold offering:
```bash
acp sell init genlayer_eval
```

Register offering:
```bash
acp sell create genlayer_eval
```

Start seller runtime:
```bash
acp serve start
```

## Local service

```bash
npm install
cp .env.example .env
npm run dev
```

## Contract

Deploy the contract to GenLayer and set:
```
GENLAYER_EVALUATOR_ADDRESS=...
```

## Testing

Direct mode tests run in-memory via `gltest` (not `pytest`):
```bash
pip install genlayer-test
gltest tests/direct/ -v -s
```

Lint the contract:
```bash
pip install genvm-linter
genvm-lint check contracts/acp_evaluator.py
```

## Notes

- ACP field names may evolve. Reconcile `offering.json` with the latest scaffold generated by `acp sell init`.
- Appeals are protocol-level on GenLayer; they are not a separate app-level contract method.
